# Design direction

`canvas/` holds the source for the interactive design canvas: phone (390x844) and tablet (834x1194) screens for every game, the player picker with age setup, the Explore games (Color Mixer, Shape Sorter, Pattern Train, Number Line-up, Brick Calculator), and the grown-ups corner.

The files are in the Claude design canvas format (`.dc.html` artboards plus `canvas.json`). They're kept here as the reference for building those screens in `src/`. The live, touch-playable version is the Brickwise Design Direction canvas on claude.ai.
